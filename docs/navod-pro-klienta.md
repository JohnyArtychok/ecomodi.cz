# Návod pro klienta — Ecomodi

## Detail produktu

- **Velikostní tabulka** 🟢 — u produktu s velikostmi vyplňte parametr „Velikostní tabulka“ (např. `klasicky-strih`, `premium`, `tanga`). Podle něj se u výběru velikosti zobrazí odkaz „Jak vybrat správnou velikost?“ se správnou tabulkou. Když parametr nevyplníte (třeba u ponožek), odkaz se nezobrazí.
